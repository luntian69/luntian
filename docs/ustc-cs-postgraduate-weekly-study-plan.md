# 中科大计算机考研：大二阶段每周学习计划

> 目标：准备 2028 年 12 月研究生入学考试，目标院校为中国科学技术大学（中科大）计算机相关方向。  
> 计划版本：大二阶段执行版  
> 原则：长期可持续、英语不断档、兼顾校内课程与专业基础。

## 一、个人情况与计划原则

- 本科背景：双非院校，计算机科学与技术专业，大二。
- 英语：词汇基础约为初中水平，语法较薄弱。
- 数学：高等数学已有学习基础，两次期末成绩均为 88 分。
- C 语言与数据结构：掌握基础语法，能看懂部分链表、树的代码，但指针理解不牢，常常无法独立写出链表。
- 校内课程：正在学习计算机网络，同时需要跟进 Java；Java 已学到类与对象。
- Java 额外课外负担：每周约 2–3 小时。
- 当前优先目标：兼顾校内成绩与考研基础，尤其避免英语学习中断。

**总体策略：英语每天坚持；Java 跟紧校内教学；C 语言集中练习独立编码；数学维持解题手感；408 以当前计算机网络课程和数据结构复习为主。**

本计划中的时间均为课外自主学习时间，不包含正常上课时间。学校作业、实验或考试周可灵活调整，不建议通过熬夜补进度。

## 二、科目优先级与每周投入

| 科目 | 当前优先级 | 建议课外投入 | 当前重点 |
|---|---|---:|---|
| 英语 | 最高，长期坚持 | 每天 60–75 分钟 | 核心词汇、基础语法、简单句分析、基础阅读 |
| Java | 校内课程优先 | 每周约 2–3 小时 | 类与对象、构造方法、封装、独立完成课堂同难度程序 |
| C 语言与数据结构 | 重点补短板 | 每周 3 次，每次 40–50 分钟 | 指针、结构体、链表、动态内存与独立编码 |
| 数学 | 保持基础与手感 | 每周 3 次，每次 30–45 分钟 | 高数复习、错题重做，按校内进度学习线代和概率论 |
| 408 专业课 | 跟随课程积累 | 每周约 2 小时 | 计算机网络课堂复盘、数据结构基础回顾 |

> 优先级并不意味着忽略其他课程。校内必修课、截止日期明确的作业和考试复习应优先安排。

**执行说明：**
- 一周约安排 14–16 小时课外学习，视任务完成情况略有浮动。

- 如果某天有实验、项目或大量作业，可以删减当天的数学或 C 训练，不要挤压睡眠。
- Java 的 2–3 小时是计划投入；如果学校作业实际需要更多时间，应优先完成课程任务，并适当调整其他学习量。
- 周日可以作为弹性日；如果本周任务已经完成，可休息，不必为了凑时长硬学。

## 四、各科执行方法

### 1. 英语：每天 60–75 分钟

目前从基础阶段开始，不建议一开始就大量刷考研真题。先建立词汇、语法和阅读习惯。

**每日参考安排：**
- 20 分钟：复习旧词并学习少量新词。
- 25 分钟：学习一个语法点。
- 15–30 分钟：分析简单句或阅读短文。

**前 12 周学习方向：**
- 第 1–4 周：词性、基本句型、主谓宾、基本时态。
- 第 5–8 周：从句、被动语态、非谓语动词入门。
- 第 9–12 周：简单阅读、句子主干分析、基础长难句。

学习建议：
- 词汇以反复复习为主，不追求单日新词数量。
- 每次语法学习后，自己造句或分析 3–5 个句子。
- 阅读时先尝试找主语、谓语和宾语，再查不认识的词。
- 如果连续几天很忙，至少保留 20–30 分钟英语复习，避免完全中断。

### 2. Java：每周约 2–3 小时

以校内教学为主，不必额外同时跟进一套完整的 Java 自学课程。

- **周一、周三：** 各用 10 分钟回忆课堂概念，记下尚未理解的问题。
- **周六：** 用 30 分钟独立写一个小程序。
- **其他时间：** 根据学校作业和课程进度灵活补足。

**练习顺序：**
1. 定义 `Student` 类，包含姓名、学号和成绩。
2. 编写构造方法，创建多个学生对象。
3. 编写实例方法，修改或打印学生信息。
4. 理解 `private`、`public` 和封装的作用。
5. 学到继承和多态后，再逐步练习对应内容。

目标是理解课堂内容并能独立写出小程序，而不是追求超前学习。如果课程作业需要更多时间，优先保证校内学习。

### 3. C 语言与数据结构：每周 3 次，每次 40–50 分钟

主要任务是把“看得懂代码”转变为“能够独立实现”。当前阶段不追求刷题数量。

| 星期 | 训练主题 | 参考任务 |
|---|---|---|
| 周二 | 指针、数组、结构体指针 | 解释指针与变量地址；练习通过指针访问结构体成员 |
| 周四 | 单链表基础 | 定义节点、创建节点、遍历、计数、查找 |
| 周六 | 链表综合练习 | 头插、尾插、删除节点，或重写本周卡住的题目 |

**每次训练流程：**
1. 不看答案，先用中文写出解题步骤。
2. 把思路转成伪代码。
3. 独立编码 15–20 分钟。
4. 卡住时只查当前不懂的知识点，不直接照抄完整答案。
5. 编译运行，测试空链表、单节点等边界情况。
6. 隔一天重新写一次，检查是否真正掌握。

前 4 周建议优先巩固指针、结构体、动态内存和链表，再逐步增加递归、树与算法题训练。

### 4. 数学：每周 3 次，每次 30–45 分钟

高等数学基础相对不错，现阶段以巩固、查漏补缺和维持解题手感为主，不必急于从头学习考研强化课程。

- **周一：** 回顾一个知识点，独立完成 3–5 道题。
- **周三：** 复习薄弱概念，练习计算与推导。
- **周五：** 做小测并整理错题。

线性代数和概率论可跟随学校课程同步推进。遇到错题时记录错误原因，并在几天后不看答案重新做。

### 5. 408：每周约 2 小时

目前正在学习计算机网络，优先利用校内课程打基础，并定期回顾已经学过的数据结构。

- **周二、周四：** 各用 10 分钟回顾课堂重点。
- **周六：** 用 25 分钟复盘本周计算机网络内容。
- **周日：** 用 35 分钟复习数据结构或完成基础题。

重点是能用自己的话解释概念、画出必要的结构图，并完成基础练习，而不是反复抄写笔记或多次观看同一段视频。操作系统和计算机组成原理暂时跟随学校教学安排，不必过早全面抢跑。

## 五、12 周阶段目标

### 第 1–4 周：建立习惯与补基础
- [ ] 英语：理解基本句型和常见时态。
- [ ] C：能解释指针、结构体指针的基本用法。
- [ ] C：独立写出简单链表的遍历与查找。
- [ ] Java：能独立创建类和对象。
- [ ] 数学：能独立完成基础复习题。

### 第 5–8 周：提高独立实现能力
- [ ] 英语：开始理解常见从句结构。
- [ ] C：实现链表头插、尾插和删除。
- [ ] Java：能完成与课堂内容难度相当的小程序。
- [ ] 数学：按计划跟进校内课程并整理错题。
- [ ] 408：能用自己的话解释计算机网络核心概念。

### 第 9–12 周：巩固与检查
- [ ] 英语：能分析简单文章中的句子主干。
- [ ] C：能独立完成数组和链表基础题。
- [ ] Java：能独立完成课程练习。
- [ ] 数学：错题有记录，并能定期重做。
- [ ] 408：建立当前已学知识的框架并完成基础练习。

阶段目标是检查方向，不是必须按日期全部完成。没掌握的内容可以延长时间，不要为了赶进度跳过基础。

## 六、从现在到 2028 年的总体路线

| 阶段 | 核心任务 |
|---|---|
| 现在至 2026 年底 | 补英语基础、练熟指针与链表，跟好 Java 和计算机网络课程 |
| 2027 年上半年 | 继续提高英语，巩固数据结构，逐步接触操作系统和计算机组成原理 |
| 2027 年下半年 | 根据大学课程推进 408 基础，数学逐步系统化，英语进入更完整的阅读训练 |
| 2028 年上半年 | 系统准备数学、英语和 408，逐步加入真题与专题训练 |
| 2028 年下半年 | 根据当年考试安排进行强化、模拟、查漏补缺，并核实目标院校招生目录 |

这只是长期规划框架。2028 年报考时，必须以中科大当年官方招生目录和考试要求为准，不能假定考试科目、参考书或复试要求一定与往年相同。

## 七、任务冲突时的取舍顺序

1. 先完成学校必修课、重要作业和近期考试准备。
2. 尽量保持英语每天学习。
3. C 语言每周至少保留两次动手练习。
4. 数学和 408 根据校内课程与实际精力调整。
5. 有余力再增加算法题，不靠熬夜追赶计划。

**大二阶段的关键成果：** 英语基础持续进步、能独立实现基础数据结构代码、数学没有明显漏洞，并且校内课程成绩保持稳定。比起过早学完所有 408 内容，这些更能为后续系统备考打好基础。

## 八、每周复盘模板

每周日花 10–15 分钟回答：

1. 本周英语学习了几天？哪些词汇或语法点还不熟？
2. 本周 C 代码中，哪些部分是自己独立写出来的？
3. Java 课堂内容和作业是否跟上？
4. 数学错题是否重新做过？
5. 计算机网络或数据结构中，能否不看笔记解释一个核心概念？
6. 下周最需要解决的一个问题是什么？

复盘的目的不是责备自己，而是让下一周更有针对性。
